# CPS Advertisement — Discovery Desk demo

The repository root `index.html` is a standalone explainer. Open **Explore the guided demo** to use `demo/index.html`.

## What the prototype demonstrates

- Seller eligibility against a €100,000 rolling annual gross-revenue ceiling.
- A Discovery Fund that separates settled value from pending compute proceeds.
- A funded, measurable minimum exposure commitment and additional funded tranches when performance supports scaling.
- Disclosed commission terms, sale attribution, return windows, refund handling, and duplicate-event handling.
- Voluntary compute contributor controls and resource-limit disclosures.
- A guided six-step walkthrough and fictional sample actions.

## Limits

This is a static prototype with fictional sample records. It does not connect to sellers, ad networks, compute providers, payment systems, or commerce platforms. It cannot launch campaigns, access device resources, verify real sales, or move money. Local interaction state is illustrative and is not a ledger. No sales, revenue, profit, or compute earnings are guaranteed.

The product requirements in the root `README.md` remain authoritative. A real pilot requires actual provider integrations, settled funding, security and privacy controls, platform approvals, and professional legal, tax, accounting, payments, and regulatory review. New production deployments are targeted at Hetzner; this static prototype does not implement deployment infrastructure.

## Run locally

Open `index.html` in a modern browser. The pages need no build step or dependencies. Google Fonts are an optional remote visual enhancement; system sans-serif fonts are the fallback.

When copying the prototype, keep the `demo/` folder together with its HTML page and JavaScript asset.
